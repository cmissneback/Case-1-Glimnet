# Cheng Lei Fan Page

A responsive fan website dedicated to the Chinese actor **Cheng Lei (丞磊)**, also known internationally as **Ryan Cheng**.

The website introduces visitors to his background, career, selected roles, interests, and memorable interview quotes. It was created as a front-end web development project and as a way to practise building an informative and visually consistent website.

## About the project

The aim of this project was to create an elegant and accessible fan page inspired by Cheng Lei’s work, particularly his roles in Chinese historical and costume dramas.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Hero section with an introduction
* Biography and quick facts
* Selected acting roles
* Interview quotes
* Information about interests and activities
* Responsive navigation menu
* Accessible semantic HTML structure
* Clear disclaimer and source information

## Technologies used
