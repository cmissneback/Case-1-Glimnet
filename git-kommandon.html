Hem Hengdian World Studios Golden Rooster-galan Galleri Git-kommandon

En fansida på svenska om den kinesiske skådespelaren Cheng Lei, gjord av en fan för andra fans.

Här är de kommandon jag använder i terminalen när jag arbetar med det här projektet.

Vanliga kommandon

Git i terminalen
Kommando Vad det gör
git init Skapar ett nytt lokalt repo
git clone "url" Hämtar ett repro från GitHub
git status Visar vilka filer som ändrats
git add . Lägger till alla ändringar i kö
git commit -m "text" Sparar ändringarna med ett meddelande
git push Skickar upp commits till GitHub
git pull Hämtar ner ändringar från GitHub
git log --oneline Visar historiken kort och kompakt

Så börjar jag ett projekt

  1. Skapa repot Case-1-HTML på GitHub
  2. Klona det till datorn
  3. Skapa mappen images och sidorna
  4. Committa ofta, minst tio gånger under arbetet
  5. Bjud in lärarna som Collaborators i Settings
Exempel på ett arbetsvarv i terminalen 
git status
git add .
git commit -m "Lagger till galleri med ljud och video"
git push
